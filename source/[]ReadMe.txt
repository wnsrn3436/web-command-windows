JunguSoft Windows [Version 1.0.0]


1. 구글 크롬의 최신버전 사용을 권장합니다.

2. 'Courier New' 폰트가 사이트의 기본 폰트입니다.

3. ASP 언어를 사용하므로, 이것을 설치해야 합니다. ('[]HowToSetupASP_1.png', '[]HowToSetupASP_2.png' 사진 참조.)

4. ASP 언어의 구동을 위해 C:\inetpub\wwwroot\폴더명 경로에 서버파일을 위치시켜야 합니다.

5. 서버파일을 위치시킨 뒤, 인터넷에서 "http://IP주소/폴더명/"으로 접속하여 결과를 확인하세요.
